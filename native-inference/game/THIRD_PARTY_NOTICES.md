## GAME model and algorithm

The native GAME implementation follows the Generative Adaptive MIDI Extractor
architecture published by [openvpi/GAME](https://github.com/openvpi/GAME),
licensed under CC-BY-NC-SA-4.0 / MIT. The converted ONNX weight lineage is the
official `GAME-1.0.3-medium-onnx.zip` release from Team OpenVPI
(commit `475a8ee781fe8cca980b3b12fbe6c80c768a813a`).
