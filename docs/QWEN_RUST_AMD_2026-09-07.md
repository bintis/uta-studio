## Concrete source differences change the comparison plan

Official QwenLM/Qwen3-ASR source `7c6daf77a2421100f5fb066495372c00129d39ff` was fetched/read, not executed (`20260907T195441-a94782dec531`). Initial audit `20260907T195623-13702730644f` is **partly superseded** by caller/backend inspection `20260907T204237-89f2c6c01bb6`, `effective-math-correction.json`. The earlier audit remains preserved, not silently rewritten:

- Official `Qwen3ASRProcessor.feature_extractor_class` is `WhisperFeatureExtractor` for both models. Legacy predict-woo instead generates **HTK-frequency triangles with Slaney area normalization** and `(n_fft+1)` bin coordinates. This is not the official Slaney-frequency bank. The pinned product worker is not modified by this finding.
- Official convolutions and encoder GELU use erf semantics. Legacy aligner uses `ggml_gelu`'s tanh approximation. The initial native configuration copied that legacy choice; `f631a56` corrects it to official erf semantics before any model graph execution.
- **Effective official eager audio attention is full valid-sequence bidirectional.** `_prepare_attention_mask` is defined but not called; audio attention receives `attention_mask=None`, and `eager_attention_forward` ignores the `cu_seqlens` kwargs. Transcribe.cpp intentionally returns an all-zero mask to match its eager reference. The initial inference “official always windows / C++ full context is wrong” was incorrect. FA2 is a distinct windowed path: the metadata800/50 would yield104-row windows for normal chunks. Retain that metadata, but do not apply a104-row mask to the native eager/ASR-reference graph or advertise a speed gain from reducing context. Legacy aligner uses windowed attention, a separate disclosed comparison difference.
- Official CNN batch padding uses the longest actual chunk. A sole49-frame chunk is padded to49, yielding7 rows—not100/13. Padding it further introduces bias-bearing convolution cells. Multi-chunk ragged tails still share the longest chunk width. Positions restart per CNN chunk; padded rows are removed.
- Both native Whisper and transcribe.cpp's **per-utterance output** drop the final centered STFT frame before global-max normalization. The earlier draft incorrectly inferred retained output from the intermediate `n_frames_for=floor+1`, without following the normalization branch. No native frontend code change is needed for this correction.

Consequently legacy C++ wall time/output is a separately labeled comparison, not an exact official-math oracle. No claim that these inspected differences establish measured quality improvement. The milestones below now include complete native ASR and explicit-word timestamp classification; alignment correctness and worker-route integration remain pending. B580 remains paused.
